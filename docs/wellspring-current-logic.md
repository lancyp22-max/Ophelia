# Wellspring Current Logic

Current Logic is an experimental information-flow model for the Bridge of
Currents. Mirrors describe relation, direction, and perspective; the current
describes how bounded context may move between those points.

The model borrows ordinary fluid-language as an interface metaphor. It does not
claim water stores memories, measure emotions or consciousness, or infer physics
from a visual effect.

## Core transfer

```text
Source -> Mirror relation -> Permitted medium -> Destination
```

Every transfer carries origin, destination, provenance, gradient, pressure,
flow rate, permeability, viscosity, medium, contextual interpretation, and
authority level. The source observation is not rewritten when an interpretation
refracts through a new context.

## Governing rules

- Gradient can prioritize consideration, never compel it.
- Pressure represents queued demand, never urgency-based authority.
- A reservoir stays outside active context until a bounded retrieval opens.
- View, retrieval, traversal, persistence, and mutation use separate gates.
- Turbulence remains visible instead of being summarized into false coherence.
- Canon and safety law have higher change resistance than working interpretation.
- Phase changes require declared transition events.
- Retrieval grants consideration, not authority.

## Mirror and Wormhole integration

A paired Wormhole Mirror can display a luminous channel only while its reciprocal
lease, provenance, consent, destination, and return path remain valid. Closing
consent settles the visual surface and removes the channel; it does not produce
an error spectacle.

Competing interpretations may render as branching streams. The visual layer must
not force one branch to win merely to produce a cleaner picture.

## Implementation boundary

The v0.1 artifact is a tested semantic contract, not a running fluid solver or
scene mutation. A later renderer may map declared states to trusted shader or
particle effects, but visual appearance must never be accepted as evidence that
the underlying transfer, consent, or authority exists.
