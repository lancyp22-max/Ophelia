# Surfaced canonization

Surfaced canonization separates a visible declaration from authorization. A
person or model may propose a transition from interpreted material to canon,
but speaking, repeating, or confidently phrasing the proposal never unlocks a
write capability.

The enforced sequence is:

`candidate → surfaced declaration → principal review → capability check → transactional write → receipt`

The affected authorized principal receives `accept`, `modify`, `reject`, and
`leave_interpreted` choices. The proposal exposes its sources, evidence,
uncertainty, affected principals, retention request, and withdrawal path before
commitment. There is no silent canonization.

## Canon integrity audit

The audit surfaces contradiction, expiry, unsupported inference, missing
provenance, supersession, withdrawn consent basis, and repeated verified
corrections. It does not use comfort, familiarity, repetition, model confidence,
or relational coherence as truth metrics. Its output is a review candidate; it
cannot automatically replace canon.

## Boundary quarantine

Quarantine applies only to observable objects crossing consequential boundaries:
generated claims, action proposals, memory-write candidates, retrieved
instructions, tool requests, state mutations, and provider outputs entering a
consequential layer. It does not claim access to hidden model reasoning and does
not classify outputs as native or foreign to a relational identity.

The gate asks what the candidate is, where it came from, what supports it, and
what scoped authority may follow. Disagreement and unfamiliarity remain
available as possible corrections rather than being treated as contamination.
